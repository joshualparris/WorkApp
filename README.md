# Dubbo Job Radar

A React + Tailwind web app for Josh and Kristy Parris to manage Dubbo job leads, score opportunities, and track applications.

## Features
- Manual job paste/import and structured job entry
- Separate scoring engines for Josh and Kristy
- Dashboard with best matches, urgent alerts, and workflow counts
- Application helper prompts and status tracking
- LocalStorage persistence for quick MVP use

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deployment
Deploy the `dist` folder to Vercel, Netlify, or GitHub Pages.
